PORTOFOLIO RENDI - PETUNJUK AWAL

1. Ekstrak folder portfolio-rendi.
2. Buka Visual Studio Code.
3. Pilih File > Open Folder, lalu pilih folder portfolio-rendi.
4. Buka index.html di browser (klik kanan > Open with Live Server jika ekstensi Live Server sudah dipasang).
5. Untuk memasang foto profil, salin foto milikmu ke folder assets dan beri nama foto-profil.jpg.
   Gunakan foto potret yang jelas. Jangan mengubah nama file agar langsung terbaca website.
6. Buka script.js dan ganti:
   - emailkamu@example.com dengan email aktif.
   - 6280000000000 dengan nomor WhatsApp aktif (kode negara 62, tanpa +).
7. Periksa kembali deskripsi, pengalaman, dan proyek. Ubah contoh proyek agar sesuai hasil pekerjaan yang benar-benar kamu miliki.
8. Setelah siap, unggah folder ini ke GitHub dan aktifkan GitHub Pages agar bisa diakses publik.

Catatan:
- Website ini menggunakan HTML, CSS, dan JavaScript biasa.
- Font Google Fonts membutuhkan koneksi internet; website tetap dapat tampil dengan font cadangan jika offline.
- Foto profil belum disertakan karena perlu menggunakan foto pilihanmu sendiri.
